تطبيق ويب وPWA عربي للرحلات البرية والكشتات في الخليج والجزيرة العربية.

> تصميم واسم وبيانات أصلية. **ليس** نسخة من أي تطبيق مدفوع، ولا يستخدم ملفات أو خرائط أو علامات تجارية لطرف ثالث.

## المزايا

| الصفحة | ماذا تفعل |
|---|---|
| 🗺 الخريطة | OpenStreetMap / تضاريس / قمر صناعي، تحديد موقع، وجهة بالنقر، آبار ومياه من OSM، حفظ بلاطات بدون نت |
| 🚙 أين سيارتي | حفظ موقع السيارة بضغطة، المسافة والاتجاه، السحب على الخريطة |
| ⏺ تسجيل المسار | مسار GPS حي، حفظ، إعادة عرض، تصدير GPX |
| 🌧 الأمطار | شبكة على الخليج من Open-Meteo (مجاني بلا مفتاح)، أقرب أماكن المطر منك |
| 📐 الإحداثيات | تحويل عشري ↔ DMS ↔ UTM ↔ MGRS، لصق نصوص وروابط خرائط جوجل، كشف الإحداثيات المقلوبة، أرقام عربية |
| 🌙 التقويم | هجري أم القرى، مواسم (الوسم، سهيل، المربعانية…)، الطوالع، أطوار القمر، مواقيت صلاة تقريبية |
| ✨ السماء | خريطة نجوم مبسّطة ونجوم الاهتداء (الجدي، سهيل، الثريا…) |
| 🏜 دليل البر | آلاف الأماكن من OSM (وديان، آبار، روضات، كثبان، قمم، مخيمات) مع بحث وفلترة |
| 🧭 البوصلة | اتجاه الجهاز + القبلة + اتجاه السيارة/الوجهة |

الوضع الليلي/النهاري، وقابل للتثبيت كتطبيق (PWA).

## التشغيل السريع

لا يحتاج تثبيت ولا مفاتيح API.

```bash
cd darb-al-barr
python3 -m http.server 8787
# ثم افتح http://localhost:8787
```

أو أي خادم ملفات ثابت (Caddy، nginx، GitHub Pages، Netlify…).
لتثبيت PWA على الجوال: افتح الرابط من Chrome/Safari ← «إضافة إلى الشاشة الرئيسية».

## ملاحظات مهمة

- **تحديد الموقع والبوصلة** يحتاجان HTTPS (أو localhost).
- بيانات الأمطار والآبار تحتاج إنترنت عند أول جلب، ثم تُخزَّن.
- مواقيت الصلاة والطوالع والمواسم **تقريبية** للاسترشاد، وليست بديلاً عن تقاويم رسمية.
- خرائط OpenStreetMap قد لا تُظهر كل الطرق الترابية؛ جودة التغطية تختلف حسب المنطقة.
- التخزين بدون نت يحفظ واجهة التطبيق + البلاطات التي طلبت حفظها (حدّ معقول لكل منطقة).
